# Statistical N-Gram Language Model for Moroccan Darija

## Project Origin & Academic Context
This project represents a natural evolution of my foundational Python coursework (Harvard CS50P). For my CS50 final project, I built a Lexical Analyzer from scratch to tokenize and count word frequencies without relying on high-level abstractions like NLTK. 

This repository scales that core logic into a functional Natural Language Processing application. Moving beyond simply counting words, this project implements an N-gram language model to predict the next most statistically likely word in Moroccan Darija—a complex, low-resource dialect characterized by non-standardized orthography and mixed Arabic/Latin scripts (Arabizi).

## Architecture & Code Structure
The model is built entirely from scratch using Python's standard library to maintain absolute transparency over the data structures and algorithms. 

*   **Data Ingestion:** Reads UTF-8 encoded CSV data containing heavily contextual conversational Darija, extracting the Latin-script Arabizi column.
*   **Tokenization Pipeline:** Utilizes Python's `re` (Regular Expressions) library to clean input, strip punctuation, and enforce lowercase normalization.
*   **Model Training:** Iterates through the corpus to construct a nested dictionary, mapping unigram frequencies and bigram state transitions.
*   **Prediction Engine:** An interactive loop that calculates the Maximum Likelihood Estimation (MLE) of user input and outputs the top three statistically probable next words.

## Mathematical Foundation
To ensure mathematical rigor, the predictive engine relies on core concepts from Probability Theory and Linear Algebra.

### 1. Probability Theory: Maximum Likelihood Estimation (MLE)
The core engine relies on the Markov Assumption, which states that the probability of a word depends only on the preceding word. The engine calculates the conditional probability of a bigram using Maximum Likelihood Estimation:

$$P(w_n \vert{} w_{n-1}) = \frac{Count(w_{n-1}, w_n)}{Count(w_{n-1})}$$

When the user inputs a word ($w_{n-1}$), the algorithm retrieves the dictionary of observed follow-up words ($w_n$) and sorts them by frequency to provide the top three predictions.

### 2. Linear Algebra: Sparse Matrices & State Transitions
Under the hood, the nested dictionary generated by the `build_model` function is an optimized representation of a sparse transition matrix. 

If we represent the entire Darija vocabulary as a vector space, the probability of moving from one word to another forms a matrix. Because most words never follow each other in natural language (e.g., "the" rarely follows "the"), storing this as a traditional matrix would be computationally inefficient.

By utilizing nested Python dictionaries, the algorithm only stores the non-zero vectors, acting as a highly efficient, dynamic adjacency list for a Markov Chain.

### 3. Out-of-Vocabulary (OOV) Handling: Backoff Smoothing
To prevent the model from crashing or returning a zero-probability collapse when
encountering an unseen word, I implemented a Backoff Algorithm. If the conditional probability of a bigram is zero, the model
"backs off" to the unigram distribution, dynamicallyoffering the highest-frequency individual words in the dataset as a fallback safety net.

## Usage
1. Clone the repository.
2. Ensure you have the `sentences.csv` dataset in the root directory.
3. Run the script: `python autocomplete.py`
4. Enter a Darija word (e.g., `wach`, `salam`, `khouya`) to receive real-time, statistically driven text predictions.
